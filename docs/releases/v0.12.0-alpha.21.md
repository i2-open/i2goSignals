# goSignals v0.12.0-alpha.21

Released: TBD

Compare: [v0.12.0-alpha.20...v0.12.0-alpha.21](https://github.com/i2-open/i2goSignals/compare/v0.12.0-alpha.20...v0.12.0-alpha.21)

## Why this release

A cluster-delivery release. Spec #112 (PR #368) replaces the delivery data
model and the router's hot path: one `deliveries` collection acknowledged by
a derived acknowledgement JTI, a `DeliveryQueue` that owns each stream's
pending references, an immutable `RoutingTable` read outside the router
lock, a `LeaseManager` that answers "do I still own this stream" from memory
instead of fencing every ack, and leases for poll transmitters and SSTP
acceptors so a request that lands on a non-owner is served by the owner
through one peer `Claim`. The two-node benchmark that drove it now reports
the verified properties and polls both nodes (#366, #367). Alongside it,
spec #114 makes the issuer's newest key decide the SET algorithm with ES256
as the default key type, the peer plane is exported as a `pkg/` surface for
enterprise to mount (#373), and spec planning#26 turns
`make build-docker-multiarch` into the family's image-publishing contract.

This alpha has several **behaviour changes operators and clients must
act on**:

- **`pendingEvents` and `deliveredEvents` are migrated into `deliveries` at
  startup and then dropped** (#359, #361). The migration runs once; API
  stream starts and deliveries access are held until it completes, and when
  the store is down at boot it runs in the background once the store is
  back. There is no reverse path: do not run an older alpha against a store
  this release has started on.
- **Acknowledgements are no longer fenced on write** (#364). Ownership is
  answered from the node's own lease tenure; `I2SIG_LEASE_SAFETY_MARGIN`
  (default `5s`, capped at half the lease duration) sets how early a node
  stops acknowledging as owner. A takeover can duplicate a send but never
  lose one.
- **Poll transmitters and SSTP acceptors now take a cluster lease** (#365).
  Every node still answers `POST /poll/{id}` and `POST /sstp/{id}`; a
  non-owner forwards the request's acknowledgements and its ask for events
  to the owner over `POST /_cluster/claim`, which uses the existing wake-up
  authentication. `I2SIG_CLUSTER_CLAIM_INFLIGHT` (default 256) caps waiting
  claims per owner. `I2SIG_POLL_DEFAULT_TIMEOUT` / `I2SIG_POLL_MAX_TIMEOUT`
  must now be set uniformly across nodes (ADR 0014 amendment).
- **New keys default to ES256, and the newest key decides the SET `alg`**
  (spec #114, #370). `POST /key/{issuer}` without `?alg=` mints the type
  `I2SIG_KEY_ALG` names (`ES256` unless set; `RS256` or `ML-DSA-65`; any
  other value stops the server at startup). A stream with no `signing_alg`
  signs with the issuer's newest active key of any type, so creating a key
  switches those streams to it. The auth-token key stays RSA. An issuer
  holding only its legacy RSA key signs exactly as before, and the RSA key
  stays in the JWKS so earlier SETs still verify. Pin `signing_alg` on a
  stream whose receiver cannot follow.
- **`build.sh` is gone; Make is the only build and publish entry point**
  (#383, spec planning#26). `make build-docker-multiarch` without `PUSH=1`
  only validates. `PUSH=1 REGISTRY=<host> NAMESPACE=<ns> TAG=<tag>` pushes
  exactly one ref and all three are required (exit 2 otherwise); it never
  tags `:latest` or `vX.Y`. The OCI `revision` label is now the full commit
  SHA and the image `version` comes from `TAG`, not `version.txt`.
- **The Go toolchain is 1.27.3** (#356, PR #385). Builds on 1.27.1 fail
  until the local toolchain is updated.

The default durability contract is unchanged: every acknowledged SET is
majority-journaled before the ack (ADR 0038). Acks run at `w:1` on the
`deliveries` state flip; a rolled-back flip redelivers and the receiver
drops the duplicate by JTI (ADR 0043, 0044 amendments).

## Cluster delivery redesign (spec #112, PR #368)

- **`deliveries` collection** (#359). One reference document per
  `(sid, jti)` with `ackJti`, `state: pending|delivered`, `createdAt`,
  `ackDate` and `expireAt`; never the body. An ack is one conditional
  `updateMany` on the stream's references whose `ackJti` matches, plus the
  inserts of any outbound copies into `events`; on Mongo 8.0+ both go in
  one client-level `bulkWrite`. Indexes are built on every start
  (`deliveries_indexes.go`).
- **Retention** (#360). `expireAt` is written at acknowledgement from the
  stream's retention policy and a TTL index reaps the reference; a bounded
  sweep purges an event body only when no delivery document in either
  state still references it.
- **Legacy migration** (#361). `MigrateLegacyDeliveries` copies
  `pendingEvents` / `deliveredEvents` into `deliveries` in batches of 1000
  and drops the old collections. Stream-update resets are queued and SSTP
  exchanges refused until delivery has started; the pre-migration poll
  refusal logs at DEBUG.
- **RoutingTable** (#362). Routing is read from an immutable snapshot
  outside the router lock; the goroutine-ID lock audit that proves it
  (`reads_under_lock_total`, `reads_before_ack_total`, design value 0) is
  always on.
- **DeliveryQueue** (#363). The queue owns each stream's pending
  references and the poll claims; wake JTIs and derived acknowledgement
  JTIs replace the per-SET stored-row read; SSTP outbound records travel
  with their reference as `OutboundSet`; a SET with no stored row, or whose
  row read fails, derives no ack JTI. A wake whose lists differ in length
  is treated as a reload; pair loops are refused after dialer shutdown and
  every stuck loop is logged. `releaseStreamLease` bounds its wait on the
  renewal loop.
- **LeaseManager** (#364). Replaces the fenced ack. Records a tenure
  deadline on every acquire and renewal; a batch inside the tenure writes
  with no lease read or coordinator call, a batch past it is skipped and
  its SETs stay pending. The renewal loop is joined before a lease is
  released. An ack batch is counted only once ownership is confirmed. The
  margin is capped and WARNed when over half the lease duration or
  negative.
- **Poll-transmitter and SSTP-acceptor leases, served through Claim**
  (#365). `poll-transmitter:<streamId>` and `sstp-server:<txSid>` leases
  (30 s / 10 s heartbeat) are taken on first use by a node whose router
  serves claims; a node that does not serve claims routes to the owner by
  wake-up. The owner applies the request's acks in its one write, claims up
  to `maxEvents` references and returns them; the receiving node signs and
  sends. `NotOwner` or a failed call forgets the cached owner and resolves
  once more; a second failure answers empty with the acks unapplied so the
  client resends. The reaper now purges deleted streams' `poll-transmitter`
  and `sstp-server` lease rows; a stream removed by reconcile releases
  every lease it holds. One `LeaseKind` type replaces the per-kind
  `Resource` wrappers. The SSTP acceptor's long-poll wait now ends when the
  client aborts.
- **PeerTransport and two-node harness** (#358). `Wake` and `Claim` behind
  one seam, with HTTP and in-process transports; package test hooks replaced
  by `AppOption` and `RouterDeps.Clock`; the test-only parity suite moved to
  internal packages.
- Retried store failures log at WARN, not ERROR. ADRs 0014, 0017, 0038, 0043
  and 0044 are amended for spec #112; `docs/Cluster.md`, `docs/SSTP.md` and
  `CONTEXT.md` describe `ackJti`, claims and `ServesClaims`.

## Metrics (#352, ADR 0047)

- `goSignals_router_queue_time_seconds` (enqueue to first hand-out) and
  `goSignals_router_ack_time_seconds` (hand-out to acknowledgement),
  histograms labelled by `tfr` only. ADR 0047: latency histograms carry no
  `stream_id`.
- `goSignals_router_stream_backlog_depth` and
  `goSignals_router_stream_backlog_oldest_age_seconds`, per-stream gauges
  reported only by the lease owner, so a cluster-wide sum counts each stream
  once and a stream with no series has no owner.
- `goSignals_router_peer_claims_total{mode,result}` and
  `goSignals_router_peer_claim_budget_exhausted_total`; `GetPendingForStreamBeyond`
  on the DAO op histogram. PromQL and alert examples in `docs/Metrics.md`.

## Signing keys (spec #114, PR #372, PR #375)

- The issuer's newest active key of any type signs a stream with no
  `signing_alg`; a pinned `signing_alg` selects the newest key of that type
  (#370). `I2SIG_KEY_ALG` (default `ES256`) sets the type of a key minted
  without `?alg=`, including the default issuer's startup key. Key summaries
  report `alg`, oldest-first (`KeyState.alg`), and every minting
  `POST /key/{name}` answers with a `Key-Id` header. ADR 0041 amended.
- `goSignals create key` saves the returned kid to `<file>.kid` beside the
  PEM, and `generate event` and `goSignalsBench` sign with the created key's
  type and that kid (#371). Doc examples that need RSA now pass
  `--alg=RS256`.
- SSTP alg tests, shared helpers and a `Key-Id` constant from the #372
  review; the Mongo `TestF1_IssuerKeys` looks the default ES256 key up by
  type (PR #375).

## Embeddable server surfaces (#373, #376, #377)

- `pkg/goSignalsServer.PeerSurface` (PR #374), sibling to `AdminSurface`,
  exposes the always-on peer routes (bootstrap, event delivery, verify,
  JWKS, poll) bound to the gateway's handlers so an external module can
  serve the peer plane with only `pkg/` imports. `/`, `/health`,
  `/.well-known/*`, `/sstp/{id}`, `/_cluster/*` and the OAuth endpoints stay
  with the embedder. Peer adapter misuse panics; nil checks run at boot.
- `PeerSurfaceConfig.Auth` is required and wins over
  `KeyService.GetAuthIssuer()`; surfaces bind their issuer into
  service-layer minting through `services.WithAuthIssuer`, and a key change
  leaves an explicit surface `Auth` alone (#376, PR #378).
- `NewPeerSurface` refuses a router built without `ServesClaims`, which
  would answer every poll empty (#377). Review follow-ups fold the key
  guard and delegate `ServesClaims` (PR #381).

## SSTP problem registry (spec #118, #379, PR #380)

- `goSetSstp.ProblemServerSuspended` (`…/server-suspended`), classed
  retryable: the admin has suspended the server pending revocation, the
  dialer keeps its redial cadence and is refused the same way until the
  suspension is lifted. Registered beside `ProblemBindingRevoked` in the
  pkg verdict table.

## Poll

- An explicit `maxEvents` of `0` is acknowledgement-only, detected on the
  wire request rather than the stored poll configuration (#369).

## Benchmark and performance

- `goSignalsBench` reports the verified properties (ack writes per batch,
  reads under lock, reads before ack, peer claims served), adds
  `--gs1b-internal` second-node receiver legs and `--poll-targets one|both`
  to poll the lease owner and a non-owner at once, labels the
  `OldestBeyond` query cost, and finishes the glossary (#366). Both poll
  receiver ids are logged under `both`. `goSignals1b` is in the server
  certificate SAN (#367).
- Two-node drains at 128 clients recorded in
  `docs/perf/throughput-baseline-alpha20.md` (#367): every leg drained
  5000/5000; POLL 2343–2492 ev/s single-target, 2042–2130 ev/s with both
  nodes polled (33–36 peer claims served, p50 about 145 ms, roughly a
  quarter of the single-target latency) and 2012–2458 ev/s with the owner
  pinned to the non-polled node (51–52 claims); zero reads under lock or
  before ack, one ack write per batch, in every run. Spec #112 re-run at
  `0ef80a4` is within the 10% noise band of the control.
- SET and `PollRequest` codecs moved to json/v2 streaming hooks
  (`MarshalJSONTo` / `UnmarshalJSONFrom`) sharing one `goSet.JSONOptionsV1`
  option set, recovering the +24–69% decode and encode regressions the
  sub-second `toe` and `maxEvents: 0` legacy hooks had introduced under
  go1.27; decode is at parity with #279 within noise, encode keeps
  +8.9% on `SetJsonBytes` from the value-receiver copy. Wire bytes are
  pinned by test (PR #382). Per-change delta rows for every slice are in
  `docs/perf/go127-baseline.md`.

## Build and dependencies

- `make build-docker-multiarch` conforms to the spec planning#26 S1
  delegation contract (#383, PR #384): validate-only without `PUSH=1`;
  `PUSH` accepts a single-word `1` or `yes`; `REGISTRY`, `NAMESPACE` and
  `TAG` are required under push with the verbatim
  `build-docker-multiarch: <VAR> is required when PUSH=1` message; one ref
  pushed, buildx metadata written to `bin/build-meta-i2gosignals.json`,
  full-SHA `VCS_REF`. `make test-multiarch-contract` pins the surface.
  `build.sh` is removed.
- Go 1.27.3 in `go.mod`, CI and `Dockerfile-dev` (#356, PR #357, PR #385).
  Security bumps: go-jose 4.1.6, mongo-driver 2.9.2, x/crypto 0.58.0,
  x/net 0.61.0, grpc 1.83.2 (CVE-2026-84445). Measured flat: identical
  allocs on all 38 benchmarks, sec/op inside noise.
- Runtime image base `cgr.dev/chainguard/bash` digest refreshed to the
  2026-10-20 image.
