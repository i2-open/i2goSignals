## Why this release

Lockstep family release, version-only. The Community SET/SSF server carries **no
code changes** since `v0.12.0-alpha.13`; this tag exists solely to keep the
goSignals family on a single, uniformly resolvable version as the enterprise,
admin, and tenancy repos advance PRD #27 (step-up activation) and PRD #54
(assurance `acr` canon) in this round. A consumer pinning
`github.com/i2-open/i2goSignals v0.12.0-alpha.14` resolves to a module identical
to `v0.12.0-alpha.13`.
