# goSignals v0.12.0-alpha.7

Released: TBD
Compare: [v0.12.0-alpha.6...v0.12.0-alpha.7](https://github.com/i2-open/i2goSignals/compare/v0.12.0-alpha.6...v0.12.0-alpha.7)

## Why this release

After the lockstep no-op of alpha.6, alpha.7 is a **substantive community
round**. It carries two headline features and the structural change that turns
community into a reusable upstream for the rest of the family.

The first is the **`pkg/goSignalsServer` admin-route surface** (#215, PR #216,
ADR 0027). The community REST admin family — stream / server / key / issuer CRUD
plus the subject-management routes — has always lived under `internal/server`,
so an out-of-tree Go module could not mount it. alpha.7 splits the router into
`peerRoutes()` (always-on) and `adminRoutes()` (the 22-route admin family) and
exposes a `pkg/`-importable wrapper an external binary mounts on its own router.
This is the **Slice-13 upstream enabler**: it lets enterprise reuse the
community REST admin handlers byte-identically — through
`goSignalsServer.NewAdminSurface(...).AdminRoutes()` — instead of re-importing
`internal/` or forking the admin contract (enterprise PRD #164 / #76).

The second is **rotate-on-GET bearer rotation with credential masking** (#152,
PR #213, ADR 0022). A GET against a stream, authenticated by that stream's
current server-issued bearer, can now mint a replacement and schedule the old
token for deferred revocation, while every admin read surface masks credential
fields to `***` by default.

Compatibility: both new behaviors are **off by default and additive**. Rotation
is gated by `I2SIG_BEARER_ROTATE_ON_GET` (default off); existing wire flows are
unchanged when it stays off. The admin-route export is a non-breaking refactor —
`getRoutes()` remains the union of the two new route sets, pinned by a
membership test, so the running server's routing table is identical. The
family continues to pin community by tag (`v0.12.0-alpha.7`).

## Admin-route surface for REST coexistence

- **#215 — export a `pkg/`-mountable admin-route surface** (PR #216, ADR 0027).
  Split `internal/server/routers.go` `getRoutes()` into `peerRoutes()` (the
  always-on peer/event/cluster routes) and `adminRoutes()` (the 22-route admin
  family); `getRoutes()` stays their pure union and route membership is pinned
  by `routers_split_test.go` so a route cannot silently cross the seam.
- Added `pkg/goSignalsServer` — `NewAdminSurface(AdminSurfaceConfig)
  *AdminSurface` / `AdminRoutes() Routes` — a caller-owned wrapper that binds the
  reused `internal/server` admin handlers onto an external module's own
  `*mux.Router`. Handler bodies are reused as-is (ADR 0021 services-lift / ADR
  0010 delivery-seam lineage); only how the application is constructed changes.
- This is the upstream half of Slice 13 (admin PRD #164): it unblocks the
  enterprise REST-coexistence binary (`I2SIG_REST_ADMIN`, enterprise #76) to
  mount the community admin family without an `internal/` import.

## Bearer rotation & credential masking

- **#152 — GET-triggered bearer rotation** (PR #213, ADR 0022). A GET on a
  stream authenticated by its current server-issued bearer mints a replacement
  (bound to the same stream id(s), old JTI as lineage parent per ADR 0007),
  persists it, returns the live value, and schedules the old token for deferred
  revocation. Gated by `I2SIG_BEARER_ROTATE_ON_GET` (default off).
- Two guards ride the constant-time match: **issuer-role** (only credentials
  this server minted rotate — a peer-supplied SSTP bearer never does) and
  **stream-binding** (the presented EAT must contain the stream; the
  management-wildcard token never rotates). Applies uniformly to RFC 8935 push,
  RFC 8936 poll, and the SSTP responder bearer.
- **Deferred revocation** via `I2SIG_BEARER_ROTATE_GRACE` (default 1h,
  0=immediate): a rotated bearer stays valid during the grace window, and an
  in-window GET with the old bearer returns the same current bearer
  (lost-response recovery) without minting a third credential.
- **Credential masking** (unconditional, not gated): credential fields read as
  the sentinel `***` on every read surface (config GET, `/state`, `/states`) via
  a non-mutating deep copy; the live value appears only in create/rotation
  responses. The update path treats an incoming `***` as leave-unchanged so a
  read-edit-write cannot clobber a live credential.
- Both env vars are documented in `docs/configuration_properties.md`.
